# Sistema Automatizado de Clasificación de Residuos

Prototipo de sistema automatizado para la clasificación de residuos generados durante el proceso de fabricación de calzados en la empresa PAPION, ubicada en Quillacollo, Cochabamba.

El sistema integra un **PLC, sensores industriales, banda transportadora, actuadores neumáticos, HMI KINCO y LOGO! Web**, permitiendo automatizar la detección, clasificación y separación de los materiales.

## 📁 Contenido del proyecto

### 📐 Diseño
- Planos eléctricos y de conexión realizados en AutoCAD Electrical.
- Diseño y modelos mecánicos.
- Modelos para impresión 3D.
- Diseño del tablero de control.

### ⚙️ Programación PLC
- Programa de control del sistema.
- Lógica de funcionamiento de la banda transportadora.
- Procesamiento de señales de los sensores.
- Control de los actuadores neumáticos.

### 🖥️ HMI KINCO
- Proyecto de la interfaz HMI.
- Pantallas de supervisión y operación local.
- Visualización del estado del sistema.

### 📱 LOGO! Web
- Configuración de la supervisión y operación mediante LOGO! Web.
- Acceso desde un dispositivo móvil conectado a la red.
