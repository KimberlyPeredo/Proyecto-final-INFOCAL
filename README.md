Sistema Automatizado de Clasificación de Residuos

Prototipo de sistema automatizado para la clasificación de residuos generados durante el proceso de fabricación de calzados en la empresa PAPION, ubicada en Quillacollo, Cochabamba.

El sistema integra un PLC, sensores industriales, banda transportadora, actuadores neumáticos, HMI KINCO y LOGO! Web, permitiendo automatizar la detección, clasificación y separación de los materiales.
